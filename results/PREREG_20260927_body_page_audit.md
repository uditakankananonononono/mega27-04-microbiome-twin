# Body-page audit criterion, frozen 2026-09-27 12:35 IST

Purpose: stop confusing total PDF pages with the requirement of 50+ body-text pages. Before measuring, define a conservative reproducible estimator: count only paragraphs whose style is `Normal`, outside the abstract and executive summary, excluding all headings, tables and their captions, figure captions, equations, appendices and references. Read DOCX in document order, start at heading `1. Introduction`, stop at heading `Appendix A.` or `References`, whichever first. Exclude paragraphs with text starting `Table `, `Figure ` and formulas represented in centered paragraphs containing a numbered equation suffix. Sum character and word counts of remaining prose. Divide prose characters by 2,500 per full text page and also by a stricter 3,000 characters per page. These are estimates, not a PDF-layout audit or a certificate. For a visual lower bound, extract PDF text per page and identify section boundaries, then manually check a sample of pages. Do not count a page mostly table, figure, heading or whitespace as a body-text page. Report both conservative estimates and PDF total, and never claim 50+ body pages from total page count alone. The counting method is fixed before its first measurement.

Execution note: `python3 scripts/body_page_audit.py` uses the system Python that has python-docx. The research `.venv-micro` environment does not have python-docx; its corresponding audit test skips by import guard, while the executed script output is checked into `results/body_page_audit.json`. The exact file hash is a separate delivery check.
