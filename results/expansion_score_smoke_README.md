# Existing cNODE-dataset score smoke checks only

The CSV/JSON pairs for Soil_Vivo and Human_Oral are derived from the already-published same-fold `bench_*_k10.json` error vectors, comparing the presence-mean model against our gLV implementation. `microtwin dependence` runs with `--n-boot 0` because each file is a *single* old ecosystem and a one-group bootstrap would be falsely precise. The resulting median **per-sample fractional error gain** is +0.111339 Soil_Vivo (678 samples) and -0.005091 Human_Oral (143 samples). These are neither the old paper's ratio of medians nor a new cross-source/causal result. They only show the API can read paired loss vectors and return the correct sign. Both datasets were already examined during development, so they cannot serve as untouched validation. The CSV row IDs are positional: historical result files did not preserve biological sample IDs, so never join them to a subject table.
