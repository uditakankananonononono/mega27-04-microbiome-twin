# Direct paired composition evaluation

The previous multi-model comparison consumed user-computed losses and could not check whether the same rows, taxon order or metric were used. This unit computes Bray-Curtis directly from bounded local relative-composition truth and prediction files. The exact rows and taxa must match in order across all models. It refuses nonfinite, negative, non-simplex, missing, duplicated, reordered or ragged inputs rather than silently dropping samples or renormalizing bad predictions. Label maps must exactly cover the same rows; one submitted subject cannot span source-family labels within that partition.

`microtwin prediction-losses TRUTH.csv --models MODELS.json --labels LABELS.csv --out NEW.json` writes a private intermediate with loss_input (errors and family labels) and provenance. MODELS.json maps 2-20 names to local prediction paths. Files are limited to 10 MB each, 10,000 rows and 1,000 taxa; the mapping is limited to 100 KB. No table values, subject or family labels are printed to stdout. The new JSON must be kept private because it contains family labels and row-level losses. All input bytes are checked for changes during evaluation.

The Python return's `loss_input` feeds the frozen comparator API. Keep validation and test evaluations separate, freeze on validation before inspecting test, and retain original evidence. This evaluator does not fit models or check a training partition, subject independence between partitions, query assemblage masks, rights, assay equivalence, resource fairness or authentic untouched-test status. It evaluates relative composition only, not SCFA concentration or absolute-abundance response. Submitted subject IDs reused with different pseudonyms evade exact label checks. Biological eligibility remains outside this numerical routine.

Tests verify hand-calculated 0.1 and 0.3 Bray-Curtis losses, a complete direct-loss to frozen-comparator workflow, CLI privacy, no overwrite, row/taxon mismatch refusal, incomplete/invalid model tables, subject-family conflict, symlink refusal and input mutation detection. All examples use invented values. No biological result, benchmark beat or discovery follows. No scientific archive, model, paper or Drive artifact is changed by this unit.
