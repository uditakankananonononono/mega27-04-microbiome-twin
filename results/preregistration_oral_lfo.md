# Pre-registration: leave-one-HOMD-family-out sensitivity (committed before analysis)
The PubTator3 continuous oral literature fraction failed to replicate the HOMD binary effect (tool 38). Test whether the HOMD association is carried by one bacterial family, especially high-multiplicity oral families.
For every HOMD family with >=2 matched oral genera in the existing KEGG GAI dataset, drop *all* genera in that family from both exposed and unexposed rows (family assigned from HOMD table, first family per genus, sorted), and refit the method-general clustered logit for gglasso and igraph: top ~ oral + GAI + log10(mean_ra+1e-6) + prevalence + C(study), retaining studies with an event. Also report the unmodified baseline. Gate: >=3 eligible families. LFO1 pass if oral coefficient >0 and two-sided p<0.05 for BOTH methods in EVERY leave-one-family-out fit. Failure is a sensitivity failure, not license to select a favorable family. No tool counted.
Script scripts/keystone_oral_lfo.py; output results/keystone_oral_lfo.json.
