# Multimodal alignment amendment, 2026-09-28 02:26 IST

The existing exact-sample-ID overlap check can label one modality `paired_metadata_candidate` and cannot detect a reused sample ID mapped to different people, source families or collection time. Keep the old diagnostic's numerical intersection for compatibility, but require at least two modalities before describing a pair. Add an optional strict alignment evaluator taking each modality's *local* records with `sample_id`, `source_family`, `subject_id`, `collection_time`, `aliquot_group`. For each common sample ID, require exactly one record per modality and exact agreement on all four nonempty metadata labels across modalities; inconsistent tuples fail closed, not silently dropped. The status can be `metadata_aligned_candidate` only if at least two modalities and the preregistered minimum number of common IDs pass. Still explicitly withhold physical aliquot, assay, rights, person/source independence and paired biological validation; no multiomic effect is estimated. Reject duplicate identifiers, blank values and extra/unknown modalities. Return aggregate counts and a keyed hash of sorted common IDs rather than raw identifiers. Synthetic tests cover single modality, mismatched subject, collection time, aliquot, source and proper aligned pair. Do not infer from row order or code/paper outcomes.
