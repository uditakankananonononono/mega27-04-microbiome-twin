# Frozen local source-admission privacy/type hardening
2026-10-07. Before new tests or code changes. Code review found an actual gap in existing screen-sources, so harden that route rather than add a new parallel wrapper.

Existing assess_source echoes arbitrary observed values for known gate keys and coerces arbitrary study objects to strings; assess_many hashes unchecked identities. A caller can accidentally include participant-like nested data in a known field, leaking it to the report or crashing the CLI outside its caught errors. Require exact nonempty, trimmed string study identities; bool/unknown/null for boolean gate fields, string-only controlled assay labels (amplicon/assembly/metagenomic/unknown), and reject extra-shaped known values without echoing input. Missing/unknown remains blocked, all metadata true remains manual review only, never final eligibility. Preserve archived eight-record results and legacy scientific metrics.

Tests: nested gate value is rejected without contents echoed; non-string/whitespace identity rejected with fixed message; invalid/unhashable rows caught as ValueError; int 1 cannot stand in for True; valid viewed inputs unchanged; duplicates remain rejected. CLI malformed-input cases return 2 with no participant strings. Run targeted tests then fresh entire suite before push. Small local CPU only, no biological fits/downloads or gate completion.
