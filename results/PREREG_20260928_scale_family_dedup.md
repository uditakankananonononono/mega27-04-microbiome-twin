# Scale-count biological-family guard, 2026-09-28 04:16 IST

The current scale gate counts unique accession strings whose four flags say verified. Two mirror accessions can still belong to one biological source family, so counting them as two independent datasets and summing their sample counts would inflate both scale targets. Require each counted verified record to carry a nonblank `source_family` label and reject duplicate family labels after whitespace/case normalization, rather than summing potentially duplicated people. Rows lacking verified flags continue excluded; a missing family in a counted row fails closed. Add `verified_biological_families` count equal to the deduplicated accession count for accepted records and an explicit caller-label caveat. Tests cover same-family cross-accession aliases and missing labels. The submitted family string is not independent proof of lineage or rights; it is only an engineering guard. No existing expansion manifest satisfies the scale target, so this correction cannot create a foundation-model result. Frozen before implementation; no model or source data read.
