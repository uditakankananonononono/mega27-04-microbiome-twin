# Predictive-dependence interval independence caveat, 2026-09-28 06:04 IST

`heldout_scores` labels caller-supplied groups as `independent_groups`, and defaults to each sample ID as a group. It can then emit a grouped interval even when no study/subject grouping has been supplied, creating a false independence impression. Retain the per-sample signed predictive gains and ecosystem median, but set interval unavailable without explicit group labels. For submitted groups, rename the count `submitted_groups` and note those labels are not proof of biological independence, source holdout or causal interaction necessity. Do not change the numeric grouped bootstrap when groups are supplied. Update synthetic tests and CLI-facing report. This is a claim-integrity correction, not a new metric or scored study. Frozen before implementation; old 160 BH calls unchanged.

Compatibility correction: the one-study oral pilot derivative used the old `independent_groups` key, falling back to 1. It now reports `submitted_study_groups=1`, `independent_studies_verified=false`, and the new interval status. The derivative JSON is regenerated; person-level gains themselves stay unchanged.
