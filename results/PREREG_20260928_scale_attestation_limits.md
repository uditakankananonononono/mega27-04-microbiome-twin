# Scale count provenance limit, 2026-09-28 05:14 IST

The engineering guard now requires a source-family label but still accepts arbitrary caller booleans (`independence_verified`, `license_verified`, `input_qc_passed`, `source_hash_verified`). Consequently a malicious or mistaken input with a thousand rows can trigger `foundation_scale_target_met` despite no independently checked external sources. Add a separate `foundation_scale_certified: false` and `leaderboard_scale_certified: false` to the returned report regardless of threshold math, and rename threshold booleans to `caller_asserted_*_threshold_met`. Keep raw asserted counts for pipeline diagnostics; document that a trusted evidence-verification workflow outside this function must certify the targets. Tests should show huge synthetic rows cross numeric thresholds but cannot certify either milestone. This is an integrity correction, not a new counted cohort or model result. No real data fetched.
