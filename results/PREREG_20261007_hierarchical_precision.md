# Frozen synthetic hierarchical precision experiment
Before simulation outcomes, October7. Question: how do repeated correlated observations change percentile-bootstrap precision when the independent unit is a submitted subject? Not a new bootstrap method, biological discovery, real-data power analysis or universal sample-size recommendation.

Known paired loss gaps D_ij = delta + sqrt(rho)U_i + sqrt(1-rho)E_ij, U/E independent standard normals. Equal repeats for each independent subject. Exact grid n={4,5,10,20}, repeats={1,10,25}, rho={0,.5,.9}, delta={0,.25}:72cells. Repeat count capped25 rather than100 in initial concept to bound compute; frozen before results.100 independent Monte Carlo panels per cell;199 bootstrap draws per panel. Fixed seed20261007, sequential generated cell streams. Primary target mean paired gap delta, equally weighted subject means. Two percentile95% intervals: naive resample all n*repeats rows and average; cluster resample n subject means and average. Statistic/cells unchanged after inspection. Quantiles default NumPy linear, .025/.975. Report coverage of known delta, strictly positive exclusion rate (lower>0), mean width, and MonteCarlo standard error for coverage. Null exclusion is one-sided false-positive diagnostic, alternative exclusion is narrow-grid detection rate, not validated study power.

100MC yields noisy rates; intervals not asymptotically certified with4/5subjects, percentilebootstrap can under-cover even when clustered. At rho0/repeats1 differences are stochastic since bootstrap draws are separate; cluster uses subject means, not hierarchical redraw of residuals. Equal repeats and homoscedastic normal model do not cover unequal sampling, compositional taxa, heavy tails, treatment allocation, model fitting, source shifts, missingness or selection. No claim that one scheme always has95%coverage. No folds/fit/heldout biology.
