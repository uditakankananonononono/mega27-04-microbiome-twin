# Chemical-panel admission contract, 7 October 2026

Frozen before implementation or fixtures. Motivation: resistant-starch census has complete attribute presence but differing finite-numeric coverage; complete subject/phase metadata does not establish a usable measured panel. This unit is offline software, no network, training or biological outcome analysis. Budget <60s/256MB.

Inputs: sample/source-family/subject, arm, phase before|during, finite numeric collection time, and analyte->explicit observed boolean. No numeric chemical outcomes accepted. Caller must separately establish units/assay/calibration/rights and convert sentinel or missing-assay values into flags with source-defined semantics. True flag is not proof of assay validity or censoring resolution.

Fixed rules: source-scoped subject keys; no duplicate sample IDs or source-subject-time coordinates; no within-subject arm conflicts; strict baseline-before-during temporal ordering; each required analyte ≥3 observed specimens in each phase by default. Report per-analyte eligible subject counts and joint eligible subject count; joint requires all analytes independently meet minima, not necessarily same specimen panel. No participant identities/output values. Full same-specimen panel is a separate stricter metric, also≥3perphase. Unknown phase/boolean malformed/rawoutcome fields rejected. No automatic imputation or eligibility threshold relaxation. Generic unit evidence must be explicitly true for admission; false means abstain. This is a design/preprocessing gate, never scientific validation, causal prediction or clinical advice.

Fixtures: complete versus analyte-specific missingness; same-specimen disagreement; sourcekeycollision; temporal leakage; duplicate technicalspecimen; unsupportedphase; nonbooleanpresence/rawoutcome rejection; unknownunit abstention. Include negative fixtures and aggregate-only/privacy assertions. Fresh fullsuite before any futurepush. No cohort export rerun under this unit.
