# Local calibrated predictor subject-leakage amendment, 2026-09-27 20:10 IST

The local `predict-calibrated` command checks that three file paths and sample IDs are disjoint, but it has no way to check whether separately named train, calibration and query samples came from the same person. Add three **optional** exact CSV `sample_id,subject_id` maps, one per partition. Either all are given or none; when given, verify each map exactly covers that partition's IDs, has unique nonblank IDs, and the three subject-ID sets do not intersect. Hash all three maps before and after the prediction, so changes during execution fail. Do not export IDs or their values in JSON. Existing no-map calls remain usable for a research-only baseline but explicitly report subject separation unverified and calibration exchangeability unverified. A passing three-map check proves only exact submitted subject labels are disjoint, not that pseudonyms hide the same person or that source/assay rights hold. Frozen before implementing synthetic tests; no live patient data are fetched or modeled. No result from this patch becomes independent external validation or a Twin Reliability Index.
