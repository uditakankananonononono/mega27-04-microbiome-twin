# ARMORD adult antibiotic source - metadata-only development lead

Original peer-reviewed study https://elifesciences.org/articles/97751/ and the publisher's source archive https://cdn.elifesciences.org/articles/97751/elife-97751-data1-v1.zip (SHA-256 `b57b1afcca8db8d101872d627cbdfd0d316bb64f321487c9d9318499c58d6c3b`). The eLife figure/data index is https://elifesciences.org/articles/97751/figures ; the paper says sequence data are deposited at ENA PRJEB86785 (https://www.ebi.ac.uk/ena/browser/view/PRJEB86785). The publisher code archive https://cdn.elifesciences.org/articles/97751/elife-97751-code1-v1.zip has SHA-256 `7b965b3b614d01eaa08e301c9411229ffc7556ed5803271c6ba93b409833ce38`. The source archive contains deidentified sample and patient maps, recorded antibiotic courses, MetaPhlAn/Kraken2 taxon profiles and resistance genes. It is public access, but downstream reuse terms and clinical-data scope still need review; public access alone is not blanket rights. The zip, identifiers and clinical metadata are not committed.

`python scripts/armord_design_screen.py /path/to/elife-97751-data1-v1.zip --code-archive /path/to/elife-97751-code1-v1.zip` checks the original zip bytes, then opens only Samples, Patients and Antimicrobial_exposures CSVs. It opens only `l_patients.csv` and `l_pairs.csv` from the separately checksum-verified code archive, and never opens taxa, resistance, drug-name values, or other model outputs. The aggregate JSON under `results/armord_design.json` contains no subject IDs or outcome values. Synthetic test rejects source hash mismatch and deliberately inserts a secret taxon table to test exclusion.

Metadata counts: 426 unique sequenced sample IDs from 225 people, 80 people with at least two sequenced samples (39 autograft, 41 allograft), 61 with at least three; no duplicate subject/day coordinates. The code archive `l_patients.csv` has 80 unique model-patient IDs but `l_pairs.csv` has 173 pairs from 79 unique people, matching the paper's 79-person longitudinal analysis. The reason one serial-sampled person contributed no model pair remains open, so a distinct paired-person unit must be used for claims. There are 5,959 recorded exposure rows among 211 people, nine with no sequenced sample; 24 rows have unparseable start/end fields. 378 event rows in 58 people have at least one sample before course start and one after end; three of those rows share an identical subject/start/end coordinate, and many drugs overlap. These are **not** 378 independent intervention courses, and observed associations in transplant recipients are not a controlled antibiotic perturbation test.

The input design is now viewed for development and must never be recast as an untouched final holdout after adaptation. Source independence beyond exact accession, matched assay/taxonomy, prediction-time treatment availability, consent/data-use, course clustering, eligibility windows, comparator and calibration remain open. No taxa, model outcome, benchmark, causal finding or discovery was scored.
