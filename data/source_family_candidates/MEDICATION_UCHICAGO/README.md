# University of Chicago medication-microbiome longitudinal lead

Original team repository https://github.com/blekhmanlab/medication-microbiome and deposit https://zenodo.org/records/19410955 (DOI https://doi.org/10.5281/zenodo.19410955 ). The GitHub README claims 3,469 samples from 1,122 clinical patients during 2020–2024 and combined metagenomic, metabolomic and electronic health record analyses across 138 medications. These are the **authors' reported totals**, not a project-verified count of antibiotic-exposed or usable baseline/follow-up units.

Zenodo record API reports open access and Apache-2.0 at the deposit level. Single `zenodo.zip` is 4,623,013,287 bytes with published MD5 `1a15c90cc506dbc03ade973716dda31a`. The archive has **not** been downloaded or inspected. The GitHub repository has no license field in its metadata; do not transfer Zenodo's deposit-level label to unrelated GitHub code or assume it settles file-level clinical data use. Review any included deidentified tables and access restrictions before processing. This source is only a candidate; antibiotic-specific exposure labels, subject/timepoint maps, source-family overlap, data rights and assays are unverified. No abundance outcomes or scores read. Do not call the published 1,122 people independent microbiome recovery tests.
