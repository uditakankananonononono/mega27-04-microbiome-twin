# Longitudinal antibiotic cohorts: source metadata only, 2026-09-26

Secondary collection https://github.com/GPZ-Bioinfo/longitudinal-microbiome-datasets at pinned commit https://github.com/GPZ-Bioinfo/longitudinal-microbiome-datasets/commit/39372a71a2814462b728561bdf38598299e345ac . Public overview contains three candidate antibiotic cohorts: Hagan 2019 (PRJNA505336 / SRP168524), Palleja 2018 (PRJEB20800 / ERP022986), Taur 2018 (PRJNA491657 / SRP162022). Exact cohort CSV URLs, SHA-256 checksums, unit counts and caveats are in `scripts/perturbation_source_screen.py` and `results/perturbation_source_screen.json`. Source files are re-fetchable but deliberately **not checked into this repository**, because participant-related metadata can include sensitive fields unnecessary for this screen. The scripts read the locally downloaded files and report aggregates only. No taxonomic profiles or outcome model scores have been used.

Retrieve only if use is justified after checking the original study's terms and intended scope. Pinned metadata URLs:

- https://raw.githubusercontent.com/GPZ-Bioinfo/longitudinal-microbiome-datasets/39372a71a2814462b728561bdf38598299e345ac/Taur_2018/PRJNA491657_metadata.csv

The secondary Hagan README mentions only 22 people (11 antibiotics/11 control). The original publication https://pmc.ncbi.nlm.nih.gov/articles/PMC6750738/ reports a second phase of 11 people (5 antibiotics), resolving the deposited combined 33 subject labels (16 antibiotics/17 control). The 264 rows have unique subject-day labels, but need original phase and taxon-table alignment before intervention-direction scoring. Palleja accession metadata has 114 runs but 57 unique sample accessions and no person/day columns there. Taur metadata has mixed sequencing strategies (3,105 16S AMPLICON rows, 14 WGS rows), and person/day metadata alone does not verify which treatment each had. Current check is **exact-accession absence** from old MGnify manifest, not proof of full mirror independence. The repository does not list a top-level license in its GitHub metadata; resolve data-use terms at the underlying source. Do not convert these into three QC-passed validation datasets. Different assays and tasks require separate comparable protocols, subject-level splits and untouched final studies.
