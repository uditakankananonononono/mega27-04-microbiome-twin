# Harris antibiotic-rotavirus trial metadata source, NOT an eligible test cohort

Original publication https://www.cell.com/cell-host-microbe/fulltext/S1931-3128(18)30375-5 . Public source analysis repository https://github.com/shandley/human_volunteer_rotabiome at exact commit https://github.com/shandley/human_volunteer_rotabiome/commit/3f7f111550e6cdccefb258d1275aff149f6ba9f0 . Its README describes 63 enrolled healthy volunteers across three arms (21 no antibiotics, 21 oral vancomycin, 21 broad-spectrum regimen) and stool collections on day -9, day 0 and day 7. Archive accession PRJEB25634 resolves to secondary ERP107569. These are enrollment/protocol counts, **not the processed metadata denominator**.

The analysis repository's mapping is https://raw.githubusercontent.com/shandley/human_volunteer_rotabiome/3f7f111550e6cdccefb258d1275aff149f6ba9f0/data/mapping_human_volunteer.txt . SHA-256 9d3ff3a057dfec48de2b9b2dd30620929d6573d3e41f436cb66d874ded056c5c. It contains participant clinical/symptom fields and is **not stored in this repo**. `scripts/harris_metadata_screen.py` checks the hash and writes only aggregates to `results/harris_metadata_screen.json`; synthetic tests do not contain real participant records. An authorized researcher may fetch the pinned source to rerun that aggregate screen after checking its rights.

Metadata screen: 122 unique sample rows, 57 distinct patient_ID labels, 34 day -9, 39 day 0, 49 day 7; 35 patient labels have both day 0 and 7. Per-arm unique patient labels are 19 broad, 21 narrow, 18 no-antibiotic; their sum 58 exceeds 57 because one patient_ID label appears under more than one arm. Do **not** assume `patient_ID` alone is a valid independent subject key or remove the conflict post hoc to improve a model score. Need source-level identity reconciliation, all-day sample-to-processed-table joins, source use terms, assay comparability, split plan and a frozen outcome before scoring. Even a valid cohort would be one study, not 63 independently held-out studies. Its metadata inputs have now been inspected for design development, so after adaptation the source cannot be represented as an untouched final test.
