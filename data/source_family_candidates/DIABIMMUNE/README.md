# DIABIMMUNE antibiotics cohort - viewed design lead, not external result

Official Broad cohort page https://diabimmune.broadinstitute.org/diabimmune/antibiotics-cohort and 16S data page https://diabimmune.broadinstitute.org/diabimmune/antibiotics-cohort/resources/16s-sequence-data . Direct published files: V4 16S closed-reference OTU table https://diabimmune.broadinstitute.org/diabimmune/uploads/attachments/93/otu_table.filtered.2Maaslin.txt (SHA-256 f202686dd96f1c6c1ec9f2b6e8c70ff0f7da655cc2697e6d91998442bf7b35bc); companion original Excel supplement https://diabimmune.broadinstitute.org/diabimmune/uploads/attachments/94/aad0917.SuppTable1.xls (SHA-256 2f6276405ffbef98dcbe84d1113ca94e960ebd8dbc35e80ed867a4e8bcf0b191). The official site says the longitudinal infant cohort includes about 39 children and repeated antibiotic courses. These are not a randomized adult-treatment comparison and age/maturation is a major confounder.

The original clinical Excel supplement is checked by its published-file checksum before a temporary LibreOffice conversion to `.xlsx`. XLSX ZIP bytes were found nondeterministic across conversions (two hashes differed with LibreOffice 7.3.7.2), so no derivative checksum is pinned. Converted bytes and underlying subject-level abundance table are **not committed**. `scripts/diabimmune_design_screen.py` inspects only OTU header IDs plus General subject IDs and the Antibiotics sheet's subject/event age columns, never abundance outcomes or symptom details. Raw copies were deleted from the working repo after aggregate QC. To rerun, re-fetch both public files and run `python scripts/diabimmune_design_screen.py --matrix /path/to/otu_table.filtered.2Maaslin.txt --supplement /path/to/aad0917.SuppTable1.xls` with LibreOffice and optional `openpyxl` installed. The script checks both original-byte hashes, sheet headers and metadata aggregates. It does not establish reproducibility across LibreOffice versions. `results/diabimmune_design.json` captures aggregates, not clinical rows.

Observed metadata: 1,101 OTU sample columns with 40 distinct ID prefixes; supplement General sheet lists 39 IDs; 38 overlap, two matrix-only and one supplement-only. Antibiotics sheet has 232 age-stamped event rows across 21 subjects, all 21 found among matrix prefixes. 218 event rows have at least one earlier and one later matrix sample; 47 event rows duplicate a subject-age coordinate, and one event subject is absent from General. These are overlapping repeated records, **not 218 independent interventions**. Sampling units, date/age rounding, event overlap, batch and rights remain unresolved. The source has now been viewed for development and cannot become an untouched final external cohort after adaptation. No model fit, calibrated reliability, benchmark or discovery.
