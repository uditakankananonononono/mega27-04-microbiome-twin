# Recovery Determinants Study (NUH) - design lead only

Original study https://www.nature.com/articles/s41559-020-1236-0 describes four human discovery cohorts and separate mouse validation. Official analysis repository pinned at https://github.com/CSB5/Recovery_Determinants_Study/commit/d374f5e7c09da659d407af5664604b81451c5df4 . Its `Data/NUH_StoolSamples_MetaPhlAn2.txt` source URL is https://raw.githubusercontent.com/CSB5/Recovery_Determinants_Study/d374f5e7c09da659d407af5664604b81451c5df4/Data/NUH_StoolSamples_MetaPhlAn2.txt , SHA-256 c978b8469113c81ec1e54a8a99e555609d52671bc039e0f62c6ce7f8dba75224. This outcome-bearing human profile table is **not committed**. The aggregate screen `scripts/recovery_nuh_screen.py` opens only its first six metadata columns plus header; no abundance values are examined. Exact units/hashes in `results/recovery_nuh_design.json`.

There are 72 sample labels representing 24 patient labels, 24 each at PRE/DURING/POST, 13 case and 11 control patient labels. This is unusually clean paired metadata, but not proof that exposures, windows, taxonomic units or patients transfer across independent cohorts. The table has 681 taxonomic hierarchy profile columns; parent and child rows are redundant, so generic summation double-counts. This is a **viewed development candidate**, not untouched external test after adapting the task. The published paper's discovery/benchmark context must be matched, and human data rights checked separately. Original mouse raw-sequence accession is SRP142225; human cohort accession references are PRJEB41865 and PRJEB41866, neither found by exact text in the old MGnify 160-row manifest. That absence does not prove independence.
