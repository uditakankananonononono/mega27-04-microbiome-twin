# ASARI multicenter adult hematology trial - public sequence header lead

Original study https://link.springer.com/article/10.1186/s12915-019-0692-y reports two hospital cohorts: Tübingen ciprofloxacin prophylaxis and Cologne cotrimoxazole prophylaxis. It recruited 68 patients, included 41 in final analysis, and had no untreated control group. Center and treatment are confounded, so a between-center difference cannot be attributed solely to antibiotic type. Original trial record https://clinicaltrials.gov/study/NCT02058888 . The paper identifies ENA study PRJEB28058 (https://www.ebi.ac.uk/ena/browser/view/PRJEB28058) as the human-read-removed sequence deposit. The paper's supplementary file collection https://springernature.figshare.com/collections/Distinct_impact_of_antibiotics_on_the_gut_microbiome_and_resistome_a_longitudinal_multicenter_cohort_study/4671044 provides figures/tables but no qualified subject/run arm map was retrieved.

Outcome-blind ENA `read_run` metadata query https://www.ebi.ac.uk/ena/portal/api/filereport?accession=PRJEB28058&result=read_run&fields=run_accession,sample_accession,sample_title,study_accession,library_strategy&format=tsv returned 164 unique WGS sample accessions (SHA-256 `406459cc1fcc3d4f5caacaa18220121ad0062eb1512abc7395457cf11b089fd8` on September 26, 2026). All 164 `sample_title` cells are simply `Human Stool Sample`, so the registry fields cannot map a run to subject, center or collection phase. The current TSV and all participant identifiers stay outside the repository. No sequence/taxon abundance outcome was read or prediction run. Do not count 164 samples as 164 patients or either hospital as an independent final study until the original subject map, source independence, license/use and same-task comparator are verified. This is a viewed design lead, not an untouched external validation result.
