# External benchmark protocol - frozen before new-candidate prediction

Drafted 2026-09-26. No new-source candidate has been fitted or evaluated. This protocol will be amended explicitly if data/eligibility checks reveal incompatible assumptions; an amendment must precede reading outcomes.

1. **Task track.** Assemblage-to-composition: input presence profile of each held-out sample, output relative abundance on a harmonized genus universe; primary error Bray-Curtis on that sample. The input presence vector itself is a strong source of information, and this task does not simulate longitudinal perturbation. Longitudinal absolute-abundance/antibiotic track is separate and requires qPCR/timepoints, with MDSINE2 eligible there, not automatically here.
2. **Source units.** Entire accession/study held out from fitting and hyperparameter tuning. No sibling run, assembly or subject can cross train/test. New MGnify candidate details live under `data/external_candidate/`; neither is approved yet for held-out scoring. HMP, American Gut, EMP each require a frozen release, source/license check and disjoint subject IDs. Mirror duplicates are one dataset.
3. **Taxonomy.** Keep named terminal genus rows only; pool compatible raw runs by biological sample before normalization; exclude derived assembly analyses. Do not accept a test study until its taxon mapping, relevant units, zeros, missing labels, read-depth and batch confounding are documented. Genus name collision fails closed. Canonical genus vocabulary and train-only prevalence filter to be frozen before test outcomes.
4. **Comparable candidates.** Presence-mean and presence-conditional prior always included; existing cNODE and gLV, plus GNN and transformer implementations, must share training data, test units, usable information and budget. Published cNODE point estimates on six original datasets are not a substitute for test predictions on the same unseen studies. MDSINE2 comparison belongs to longitudinal track only.
5. **Primary verdict.** Per eligible unseen study compute median Bray-Curtis per method. Macro-average those medians so a 900-sample study does not overpower a 20-sample study. The benchmark challenger must beat the strongest eligible model under the same task, with study-level paired bootstrap 95% interval of candidate-minus-baseline fully below zero; compare all predeclared model families and control multiplicity. Baseline choice itself must use disjoint validation studies, not select the strongest by peeking at the final test set. A later all-model leaderboard can show each test performance without using test-best selection to certify a win. With fewer than two independent external studies, mark insufficient. Report losses, model failures, compute, domains and number of eligible studies. `microtwin.leaderboard_stats.compare_by_study` implements only a paired macro/bootstrap statistic: even a favorable interval is labeled statistic-only, and `external_win_certified` is always false pending separately verified source-family, untouched-test, same-task, comparator-selection and multiplicity gates. It is not the full multi-model leaderboard.
6. **Discovery and reliability.** Do not infer causal interaction necessity from predictive gain. Intervention direction tests require held-out labeled perturbations; uncertainty must be calibrated on train/validation sources before claiming a Twin Reliability Index. A clinical action is outside this research platform.

Success is not guaranteed. Until eligible untouched studies, all model-family baselines and the protocol's statistics are run, the claim “beats the top tool” is **MISSING**, not a near-win.
