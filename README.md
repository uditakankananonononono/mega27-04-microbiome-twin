# mega27-04-microbiome-twin
Microbiome digital twin: predict community composition from species assemblage, benchmarked on the six real ecosystem datasets of the cNODE study (Michel-Mata et al. 2022, PMC9221840; data via github.com/yixueyang/cNODE).
Models on identical folds: presence-mean null, cNODE re-implementation, gLV replicator, GraphTwin (attention GNN over present taxa with learned interaction gates).
Run tests: `python -m pytest -q`. Run benchmark: `python run_bench.py Drosophila_Gut presence_mean,cnode,glv,graphtwin 10`.

## GraphTwin v2 (TwinStack) and v2b (ConstStack)
TwinStack (`graphtwin2`): per-sample convex combination of the four base predictors,
weights from a small MLP gate over assemblage summaries, trained on inner out-of-fold
predictions (no leakage; PREREG_graphtwin2.md). ConstStack (`graphtwin2b`): constant
per-dataset simplex weights + inner-OOF base-subset selection (PREREG_graphtwin2b.md).
Run: `python run_bench.py Human_Gut graphtwin2 10` (or `graphtwin2b`).
Numerical-safety: any NaN base prediction falls back to the presence-mean null's.

## A concrete local research baseline

`microtwin predict TRAIN.tsv QUERY.tsv --unit counts --source-id my-study --processing-authorized --out predictions.csv` now produces a real, local composition prediction for each research sample's binary taxon-assemblage query. The labeled training table has `sample_id` followed by taxa abundance columns; the query has disjoint `sample_id` values and exactly the same taxon columns and order, with **only 0/1 presence indicators**. Both files must be CSV/TSV, under 50 MB each. It normalizes labeled training abundances, averages taxa across training samples, masks absent taxa in each query, then renormalizes. For example, training rows `(A=8,B=2)` and `(A=4,B=6)` with query `(A=1,B=1)` yield predicted `(A=.6,B=.4)`. The output is a local CSV, plus a provenance and abstention report on stdout; no upload occurs. Queries containing a present taxon never observed in training, input overlap, malformed data, or mismatch in taxon order are rejected.

This is a **working research baseline**, not a novel discovery, interaction model, person-specific intervention forecast, deployed upload service or validated digital twin. The caller declaration is not proof of rights; subject grouping is optional metadata and no claimed external evaluation follows from this command. Matching names alone do not establish taxonomy or assay compatibility. Prediction intervals and the Twin Reliability Index are unavailable. All source-family validation and benchmark gates in `BENCHMARK_PROTOCOL.md` still apply to any performance claim.
The CLI refuses an existing output path to avoid overwriting a prior result or an input file. Choose a new path for each run; the JSON on stdout records the selected path and input hashes.

The predictor formula is the same presence-mean model used in the original six cNODE-table benchmarks. `python scripts/local_predict_six_dataset_check.py` reruns ten-fold, same-dataset cross-validation on all six locally held cNODE matrices, with source-file checksums. Its observed median Bray-Curtis errors (Ocean 0.093174; Drosophila gut 0.171519; Soil in vitro 0.205478; Soil in vivo 0.123690; Human oral 0.203918; Human gut 0.256350) are internal diagnostics of the working predictor, **not** unseen-source validation or a top-tool comparison. The script and regression test anchor the CLI model to the archived numeric baseline; input samples are deduplicated by assemblage as in the archived experiment. Different cross-validation protocols must not be mixed.

## Local split-calibrated error radius (research only)

`microtwin predict-calibrated TRAIN.tsv CALIBRATION.tsv QUERY.tsv --unit counts --source-id my-study --processing-authorized --out predictions.csv` predicts the same population-prior composition as `predict`, then uses a disjoint labeled calibration table to compute an upper Bray-Curtis error radius at nominal `1-alpha` marginal coverage (default `--alpha 0.1`). It reports the rank `ceil((n_cal+1)(1-alpha))`; if that rank exceeds the calibration count, the radius is the vacuous maximum 1.0. This new local command requires identical taxon columns/order and disjoint sample IDs across training, calibration and binary query, checks file hashes and refuses overwrite. The prediction CSV contains compositions; the error radius and source checks appear in JSON stdout. The two-row calibration smoke example gives a vacuous radius and cannot be marketed as useful certainty. `scripts/internal_conformal_check.py` reports observed same-dataset coverage on six archived tables, including below-90% realizations. Optional `--subject-map TRAIN.csv --calibration-subject-map CAL.csv --query-subject-map QUERY.csv` requires all three exact `sample_id,subject_id` maps and rejects exact subject-ID overlap across partitions. Without all three the report says subject separation is unverified. Matching pseudonyms are a useful leakage guard, not proof that differently named people are unrelated, or that source/assay/exchangeability is established. No score becomes a clinical guarantee or the final Twin Reliability Index.

The finite-sample rank guarantee requires exchangeable calibration/query pairs and a predictor fitted **without calibration outcomes**. A matching `--source-id` string and a caller authorization flag do not establish assay harmonization, independent subjects, rights or exchangeability. This radius is not a conditional/person-specific interval, an external-source guarantee, an intervention forecast, a medical risk measure or the five-component Twin Reliability Index. Neither the model nor this command has been certified as a clinical digital twin.

`python scripts/local_calibrated_six_dataset_check.py` drives the actual calibrated command over disjoint 60/20/20 candidate splits of each already-viewed cNODE table. It verifies predictions against the archived PresenceMean implementation and recalculates the radius independently, then counts abstentions for taxa absent from training. The *admissible-row* test coverage at nominal 90% is Ocean 51/55, Drosophila gut 6/6 (vacuous radius 1), Soil in vitro 9/11, Soil in vivo 120/135, Human oral 27/28, Human gut 19/22. Ocean drops one calibration row; Soil in vivo drops three calibration/two test rows; Human oral drops two calibration/two test rows for unseen present taxa. Exact candidate and scored denominators, hashes and maximum numerical deviations are in `results/local_calibrated_six_dataset_check.json`. These filtered rates are a **different estimand** from the earlier unconditional internal split check, and neither establishes external-source exchangeability or patient-specific reliability.

### Measurement contract gate

`microtwin check-assays examples/nasa_assay_contracts.json` compares declared source family, material, assay, taxonomy version, processing pipeline and unit. Any measurement mismatch returns exit code 2 and an abstention report. Same fields return a request for source validation, not permission to transfer or a certified twin. These are caller declarations, not independently verified provenance. The NASA example intentionally demonstrates incompatible V4/shotgun contracts; its amplicon taxonomy version is labelled unverified and must not be used as factual metadata. RR-5/6 showed that equal genus names need not give equal abundances. This separate preflight command is not automatically invoked by legacy audit/predict commands; users must not mistake it for enforced endpoint admission or a deployed website. Existing predictions remain research-only population baselines.

Use `microtwin predict-checked TRAIN QUERY --contracts CONTRACTS.json --unit counts --source-id SOURCE --processing-authorized --out NEW.csv` for the strict route: measurement fields must match, both contracts must name the same source family, and contract source/unit must match the request. Cross-source prediction abstains until a validated bridge is implemented. The output records a contract hash; declarations are not independent evidence and this is still a population baseline, not an individual ecological or clinical twin. Legacy `predict` and `predict-calibrated` remain available for archival reproduction and do not enforce these new contracts.
