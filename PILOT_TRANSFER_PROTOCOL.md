# Oral-to-oral cross-study PILOT, locked before reading candidate prediction errors

Train accession: existing MGnify audit pilot MGYS00002394, 20 biological samples, source https://www.ebi.ac.uk/metagenomics/api/v1/studies/MGYS00002394/pipelines/4.1/file/SRP051741_taxonomy_abundances_SSU_v4.1.tsv . Test accession: new candidate MGYS00002146, 178 runs pooled into 87 site samples grouped as 58 people, source https://www.ebi.ac.uk/metagenomics/api/v1/studies/MGYS00002146/pipelines/4.1/file/SRP009299_taxonomy_abundances_SSU_v4.1.tsv . Both MGnify pipeline v4.1, but disease/site and 454 sequencing design may differ. Subjects across studies are not linked, so true independent-subject status beyond accession disjointness is unverified. This is a **pilot**, not the final untouched cross-family benchmark or a 500-1000-dataset leaderboard.

Fixed process: select terminal named genus taxonomic rows, use all 160 train genera as vocabulary, pool candidate test runs by MGnify sample ID before relative normalization, map paired oral sites to the same person, project test counts onto train vocabulary, exclude zero-mass projected samples, report all exclusions and retained-mass distribution. Do not select features by test prediction error. Normalize assemblage presence and composition after projection. Fit on all 20 train samples with existing `fit_predict` deterministic seed 0 for presence_mean, cnode, glv, graphtwin and transformer. No hyperparameter tuning on test, one fit per model; record prediction failures. Primary descriptive metric is median Bray-Curtis by each person (sites aggregated within person); secondary per-sample median and individual errors. No inferential external-study win, because there is just one test study and study-level uncertainty is unavailable. Any model class may lose. Output full errors, source SHA-256, code commit and protocol hash. This pilot may guide debugging, not certify the requested top-tool beat.
